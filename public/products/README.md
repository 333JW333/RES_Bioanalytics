# Product Photos

Real product vial photos go here. Naming convention (matches the pattern
used in `public/coas/`): `<product-slug>-front.jpg` and
`<product-slug>-back.jpg` (or `.png` — either works).

Example for SS-31:
- `ss-31-front.jpg`
- `ss-31-back.jpg`

Once a pair of images lands here, tell Claude and it'll wire them into
that product's card and detail page — no other manual step needed.
