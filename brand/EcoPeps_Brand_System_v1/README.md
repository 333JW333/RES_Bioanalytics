## Locked geometry

The center-aperture radius is exactly 10% of the visible torus radius in every newly drawn mark. The detailed mark uses 28 loops; the flat mark uses 20; the micro mark uses 8.

## File notes

SVG is the preferred source for web and general vector use. PDF/EPS are the preferred print handoff. The `.ai` file is a legacy Illustrator-compatible EPS containing editable paths. The photoreal raster masters preserve the approved artwork exactly; the controlled vectors are original rebuilds for scale, consistency, and small-format reproduction.
